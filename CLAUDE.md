# CLAUDE.md — 2026-phd-storybook

An illustrated storybook retelling of Pingfan Hu's PhD dissertation (three connected
BEV smart-charging studies) in 24 landscape spreads: prose on the left, warm
Ghibli-style watercolor art on the right. Two synchronized editions (English and
Chinese) and three deliverables in `output/`: the interactive flipbook
(`book.html`, page-curl flip, EN/中文 toggle, PDF buttons) and the two print PDFs.

This is a PUBLIC repo, and it is also the website: GitHub Pages serves `docs/`
(built by `render/deploy.sh`) at https://pingfan-hu.github.io/2026-phd-storybook/.
The project graduated out of the private `papers` repo, where it was developed.

Inspired by Rachel Coxcoon's dissertation storybook. Audience is PhD-level readers
(researchers, professors, students): simplify the content, never the reader.

## Structure

```
2026-phd-storybook/
├── content/                # SOURCE OF TRUTH for all text
│   ├── 00-source-facts.md  # per-study headline findings and numbers (facts gate)
│   ├── 01-storyboard.md    # historical spread-by-spread outline (superseded)
│   ├── 02-transcript.md    # English transcript: 24 spreads, prose + image briefs
│   └── 03-transcript-cn.md # Chinese edition, mirrors the English spread for spread
├── characters/
│   ├── original/           # real photos of the cast
│   ├── cartoon/            # Ghibli portraits generated from them
│   ├── CHARACTER.md        # who's who, casting weight, per-person "Look" specs
│   ├── generate_portraits.py  # original/ -> cartoon/ (Gemini image-to-image)
│   └── build_sheets.py     # tiles portraits into cast sheets for group scenes
│                           # (characters/sheets/ is derived, untracked; rebuild on demand)
├── charts/
│   ├── original/           # real figures from the three published studies
│   ├── cartoon/            # warm-palette repaints of those figures
│   ├── CHARTS.md           # what each chart shows and which spread uses it
│   └── make_cartoon.py     # original/ -> cartoon/ (Gemini image-to-image)
├── images/                 # final spread art: spread-01.png .. spread-24.png
│   ├── generate_scenes.py  # scene prompts (one per spread) -> Gemini
│   ├── integrate_charts.py # pastes cartoon charts onto frames/screens in scenes
│   └── make_backcover.py   # spread 24 only (needs legible text; GPT-Image backend)
├── render/
│   ├── build.py            # transcript -> print HTML -> PDF; includes the fit check
│   ├── build_book.py       # both transcripts -> output/book.html (flipbook)
│   ├── styles.css          # print layout tokens and spread geometry
│   ├── book-assets/        # web-sized JPEGs of the spread art (derived via sips)
│   ├── vendor/page-flip.browser.js  # StPageFlip 2.0.7 (MIT), inlined into book.html
│   └── deploy.sh           # rebuild everything and assemble docs/
├── output/                 # deliverables: book.html, storybook.pdf, storybook-cn.pdf
└── docs/                   # the published website (index.html + assets + PDFs),
                            # generated by deploy.sh, served by GitHub Pages
```

## Build commands

```bash
# From this directory:
python3 render/build.py              # English PDF  -> output/storybook.pdf
python3 render/build.py --lang cn    # Chinese PDF  -> output/storybook-cn.pdf
python3 render/build.py --html       # print HTML + fit check only, no PDF
python3 render/build_book.py         # flipbook     -> output/book.html (+ book-assets)
bash render/deploy.sh                # rebuild everything + assemble docs/ (the site)
```

Publishing = `bash render/deploy.sh`, then commit and push. GitHub Pages serves
`docs/` on main; the site is index.html (the flipbook with rewritten asset
paths), book-assets/, and the two PDFs.

The fit check runs on every build: prose is vertically centered and would silently
eat the page margin if too tall, so build.py measures every spread in headless
Chrome and fails (exit 3) listing any spread whose prose exceeds the text pane.
Fix by trimming prose, not by disabling the check.

## How it was made (and how to change it)

1. **Facts first.** `00-source-facts.md` distills the dissertation
   (`2026-phd-defense/paper.qmd` in the private `papers` repo). Every number in the
   transcripts must trace here.
2. **Transcripts.** `02-transcript.md` is the English source of truth; each spread is
   `## NN | type` + prose + a fenced `::: image` brief. `03-transcript-cn.md` mirrors
   it (same spreads, types, briefs; natural idiomatic Chinese, not literal
   translation). ANY content edit to one MUST be mirrored in the other.
3. **Cast.** Real photos (`characters/original/`) -> Ghibli portraits
   (`generate_portraits.py` -> `characters/cartoon/`). Group scenes need cast sheets:
   run `characters/build_sheets.py` first (recreates `characters/sheets/`).
4. **Charts.** Real study figures (`charts/original/`) -> warm cartoon versions
   (`make_cartoon.py` -> `charts/cartoon/`), composited onto surfaces in scenes by
   `images/integrate_charts.py` so the book shows actual findings.
5. **Scenes.** `images/generate_scenes.py` holds one prompt per spread plus the shared
   STYLE block (realistic present-day world, Ghibli painting style only, no floating
   symbols, no text). Regenerate a single spread: `python3 images/generate_scenes.py 06`.
   Image generation needs `NANOBANANA_GEMINI_API_KEY` (ph-image skill, in ~/.zshrc).
6. **Render.** `build.py` parses the transcript into spreads and prints via headless
   Chrome; `build_book.py` reuses that parser to emit the flipbook with both languages
   baked in (page geometry matches print exactly, so text wraps identically).

## House style and rules

- No em dashes anywhere, in any language. Abbreviations defined on first use.
- The advisor is introduced once as Professor John Paul “JP” Helveston, then JP.
- The protagonist: 胡平凡 (Pingfan Hu) once in the CN edition, then 平凡.
- One idea per spread; research logic (motivation, method or finding, implication).
- Keep transcripts' image briefs in English in both editions (they are shared).
- After editing transcripts, rebuild BOTH PDFs and the flipbook.
